# PSTools command reference

## Active Directory

| Command | Synopsis |
|---|---|
| [Disable-ADUser](ActiveDirectory/Disable-ADUser.md) | Deprovisions a user in on-premises Active Directory. |

## File System

| Command | Synopsis |
|---|---|
| [Get-DiskUsageReport](FileSystem/Get-DiskUsageReport.md) | Shows the largest folders (recursively) and the largest files under a path. |

## Intune

| Command | Synopsis |
|---|---|
| [Remove-IntuneDevice](Intune/Remove-IntuneDevice.md) | Removes devices from Intune by serial number, and optionally from Windows Autopilot and Entra ID. |

## Microsoft 365

| Command | Synopsis |
|---|---|
| [Disable-M365User](M365/Disable-M365User.md) | Deprovisions a user in Microsoft 365 (Exchange Online + Entra ID). |
| [Get-M365AdminMfaReport](M365/Get-M365AdminMfaReport.md) | Reports the MFA registration status of every Entra ID directory role holder. |
| [Get-M365GroupMember](M365/Get-M365GroupMember.md) | Lists the user members of an Entra ID / Microsoft 365 group, optionally exporting them to CSV. |
| [Get-M365License](M365/Get-M365License.md) | Reports the last sign-in of licensed Microsoft 365 users, to find licenses that are assigned but not used. |
| [Get-M365MailboxSpaceReport](M365/Get-M365MailboxSpaceReport.md) | Analyzes where space is being used in an Exchange Online mailbox. |
| [Get-M365PasswordLastSet](M365/Get-M365PasswordLastSet.md) | Shows the Microsoft 365 users whose password was set longest ago. |
| [Get-M365Room](M365/Get-M365Room.md) | Searches for Microsoft 365 room mailboxes. |
| [Get-M365RoomList](M365/Get-M365RoomList.md) | Lists Microsoft 365 room lists (locations/buildings). |
| [Get-M365User](M365/Get-M365User.md) | Shows a brief overview of a Microsoft 365 user, similar to the user page in the Microsoft 365 admin center. |
